UNDER THE HOOD
What happens when you press Run?
  1. Your chosen route receives the prompt.
    The frontend forwards the request through its server to Switchyard.
  2. Your chosen routing policy selects a destination.
    Direct always uses one model. Weighted random samples a pool. System One evaluates specialist advantage, while an LLM classifier generates a capability verdict.
  3. Switchyard applies the configured threshold.
    The selected free model generates the answer. Preview mode stops at selection. Direct and random previews make no judge calls.
Classifier previews call their judge; direct and random previews select locally. Classifier probabilities are not exposed by this Switchyard API, so the UI does not invent confidence scores. Free provider quotas and availability still apply.
